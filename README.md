# 탐뷰티 · 4주 마케팅 전략

[발표 화면 열기](https://gimyedalm-collab.github.io/tam-beauty-growth-brief/)

국내 TikTok Shop 도입에 대비하는 탐뷰티 마케팅 검토용 제안입니다. 국내 개점일은 확정 정보로 제시하지 않습니다.

- 본문 5장, 근거 자료, 발표자 설명, 검토 메모
- 방향키: 슬라이드 이동 · N: 설명 · F: 전체 화면
- 검토 메모는 작성한 브라우저에만 저장됩니다. 공유하려면 내보내기를 사용하세요.

GitHub Pages는 `main` 브랜치의 루트에서 게시됩니다. `index.html`에 발표에 필요한 이미지와 글꼴이 포함돼 있습니다.
